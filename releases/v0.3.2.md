# v0.3.2

**Released:** 2026-06-08

Changes since v0.3.1 (`11829b3`..`312d0fa`).

## Infrastructure

- **Cleaner Docker image tag format** (PR #93 by @CaTeIM, follow-up to #91): Published image tags now drop the leading `v`, so the pull command reads `docker pull akitaonrails/frankmd:0.3.2` instead of `:v0.3.2`. The git tag convention is unchanged (the workflow still triggers on `v*` tags), only the rendered image tag is normalized. The previously published `:v0.3.1` image stays on Docker Hub untouched; this only affects future releases. `:latest` is still published on every tagged release.

## Test Coverage

- 449 Ruby tests, 1,393 JavaScript tests (1,842 total) — unchanged from v0.3.1.
