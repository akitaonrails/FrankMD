# v1.11.1

Hotfix release.

## Fixed

- `GET /recent_files` with an `Accept: application/json` header returned 500 (`ActionView::MissingTemplate`) — the Home partial was rendered without an explicit format. It now renders the HTML panel for any accept header, with a regression test pinning the JSON-accept case. Found during v1.11.0 live verification.
