# v1.13.0

**Released:** 2026-10-31

Explorer ergonomics release: four maintainer-shipped improvements from open issues, plus consolidated dependency bumps.

## Added

- **Empty-area explorer interaction (closes #261, closes #267)**: a right-click on the explorer's empty surface clears the active selection (so toolbar New Note / New Folder target the root again) and opens an application dropdown menu at the click point with New Note, New Folder, Select All, and Find File. The menu clamps to the viewport, closes on outside clicks, item selection, and Escape, and Select All highlights every visible item. Copy localized in all seven locales.
- **Multi-selection drag (closes #266)**: dragging an item that belongs to the current selection now carries the whole selection — files and folders together — to the drop destination. Items already covered by a selected ancestor folder move with that folder (the same guard the bulk delete applies), items already at the destination are skipped, and the move loop stops at the first failure so a partial move cannot keep relocating the group.

## Fixed

- **Items created inside a collapsed folder stay visible (closes #268)**: creating a note or folder with a collapsed selected destination now opens the destination (and its ancestors) before the request, so the re-rendered tree reveals the new item instead of hiding it until the folder is opened by hand.

## Dependencies

- bootsnap 1.26.1 (+msgpack 1.8.7), tailwindcss-rails 4.7.0 (+tailwindcss-ruby 4.3.3, rack 3.2.8, rack-test 2.3.0, io-console 0.9.5, prettyprint 0.2.1), ruby/setup-ruby v1.335.0 and docker/login-action v4.7.0 (action SHAs verified against upstream tags). Rebuilt Tailwind output is selector-identical.
- CI runners pinned to ubuntu-24.04: `ubuntu-latest` now resolves to 26.04, where ruby 3.4.8 has no build.
