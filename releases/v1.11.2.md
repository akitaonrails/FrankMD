# v1.11.2

**Released:** 2026-10-25

Fix release: moved notes stay visible, plus a repaired system-test suite.

## Fixed

- **Moved notes were hidden in collapsed folders**: dragging a note into a collapsed destination folder recorded the expansion only after the rename response had already re-rendered the tree, so the note appeared to vanish. The destination folder (and its ancestors) is now expanded before the request, and revealed in place for other dispatchers of the move event. Covering unit tests fail without the fix, including nested destinations.

## Tests

- **Draft-recovery system suite green again (closes #254)**: two multi-statement `evaluate_script` blocks were syntax errors under Selenium's `return (SCRIPT)` wrapping ("Unexpected token 'const'"), killing the tests with unrelated JS errors; they are IIFE-wrapped, and a new convention guard in `test/helpers/` rejects that shape suite-wide (verified to fail on a planted offender). Remaining drift was stale expectations, corrected: expand a folder before clicking a nested note, disambiguate folder-vs-header selectors, drive the app-styled delete confirmation from #188 instead of `accept_confirm`, and respect the by-design refusal to delete a non-empty folder.
- Full system suite: 78 runs, 553 assertions, 0 failures.

## Test Coverage

- 1,144 Ruby tests (4,394 assertions), 2,204 JavaScript tests (96 files), 78 system tests; full `bin/ci` and hosted CI green on the release tree.
