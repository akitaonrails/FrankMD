# v1.7.0

**Released:** 2026-10-08

Changes since v1.6.1 (`v1.6.1`..`c45418e`).

## Features

- **Explorer selection + keyboard actions** (#215, PR #218 by @rafaself): folders are now selectable in the Explorer, with keyboard shortcuts for navigation and file actions.
- **Settings in a modal dialog** (#217, PR #220 by @rafaself): settings moved into a standalone modal, decoupled from the editor workspace.
- **Configurable click-to-recenter** (#221, PR #222 by @rafaself): the cursor-recentering behavior after an editor click is now a setting (can be turned off).

## Fixes

- **Typewriter preview vertical alignment** (#216 + related centering, PRs #219 and #213 by @rafaself): display content in the Typewriter preview is now top-aligned/centered correctly.

## Dependencies

- KaTeX 0.16.47 -> 0.19.0 (re-vendored, still fully self-hosted — no CDN; all fonts local).
- Dev dependencies updated to clear `npm audit` findings (test tooling only; not shipped in the importmap runtime).

## Test Coverage

- 934 Ruby tests, 2,023 JavaScript tests (2,957 total).
