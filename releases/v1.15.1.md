# v1.15.1

**Released:** 2026-11-14

Maintenance release with the latest dependency updates.

## Dependencies

- **ruby_llm 2.1.1 → 2.2.0**: the grammar checker's client. The 2.2 release renames some internals, so the integration was re-verified beyond the test suite: the configuration keys FrankMD sets still exist, `RubyLLM.chat` still accepts `provider`/`protocol`/`assume_model_exists`, and both the OpenAI-compatible gateway and Ollama chats construct with `with_instructions`/`ask`. FrankMD does not use persisted chats, so the 2.2 database migration does not apply.
- **aws-sdk-s3 1.239.0 → 1.242.0** (with aws-sdk-core 3.268.0) for S3 media storage.
- **CI actions**: `ruby/setup-ruby` v1.336.0 → v1.338.0 and `docker/login-action` v4.7.0 → v4.8.0, both pinned by SHA and verified against their upstream tags.

## Test Coverage

- 1,182 Ruby tests (4,671 assertions), 2,281 JavaScript tests (99 files), 92 system tests (742 assertions).
- Full `bin/ci` and the complete system suite green on the release tree, plus a runtime check that the AI client still constructs chats for the gateway and Ollama providers.
