# v1.16.0

**Released:** 2026-11-23

Configurable Google image-search infrastructure, recursive folder deletion, a
Ruby security update, and the latest compatible dependency releases.

## Added

- **Recursive folder deletion (closes #282)**: confirmed folder deletion now
  removes nested notes, attachments, and subfolders. The operation explicitly
  rejects the notes root, stays under FrankMD's filesystem and recent-history
  locks, and uses symlink-safe removal so links inside the deleted tree cannot
  remove external targets. Active nested drafts are preserved before the
  request and resume if deletion fails.
- **Configurable Google Custom Search endpoint (#277, by
  [@Specstreamai](https://github.com/Specstreamai))**: image search can use
  `google_cse_endpoint` / `GOOGLE_CSE_ENDPOINT`, while Google's endpoint remains
  the default. The setting is forwarded through Docker Compose and both `fed`
  shells. Documentation calls out that custom endpoints receive the configured
  API key, search-engine ID, and search terms.

## Security
