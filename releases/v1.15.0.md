# v1.15.0

**Released:** 2026-11-07

External-edit protection for saves, a new grammar-check provider, and a broad dependency refresh including the editor stack.

## Added

- **External-edit protection (closes #272)**: every save now carries the revision the note was loaded with. If the file changed on disk in the meantime — another editor, another machine, a sync client — FrankMD shows a side-by-side diff instead of silently overwriting it. Keep the server version (reloaded in the editor) or keep yours (saved on top of the new revision). Text typed while the request was in flight is never replaced by the older snapshot, and the conflict is scoped to its own note even if you switch documents with the dialog open. The check is best-effort against writers that ignore FrankMD's lock, such as sync tools writing mid-save.
- **Cheaper Inference provider for grammar checking (#273, by [@aiapienthusiast](https://github.com/aiapienthusiast))**: an OpenAI-compatible gateway selected through `ai_provider = cheaperinference`, configured with `cheaperinference_api_key` and `cheaperinference_model` (default `gpt-5.4-mini`). It sits after OpenRouter in auto priority. The API key is masked like the other providers and the endpoint is a fixed constant.

## Fixed

- **Save responses were never parsed**: `@rails/request.js` exposes the body as a `json` getter, so the autosave success path threw while reading it and the returned revision was silently dropped. It is read correctly now, which is what makes revision tracking and conflict detection real.
- **AI provider isolation under concurrency**: RubyLLM keeps its configuration in a process-global object that a chat reads when it runs, so overlapping requests could pair one provider's key with another provider's endpoint. Configuration and chat now run under a mutex.
- **Two stale system tests** from v1.14.0: the Settings theme test assumed `tokyo-night` was the last option (the Omarchy theme is appended when detected), and the workspace layout test clicked opacity-0 pins in rows that have no layout at some breakpoints.
