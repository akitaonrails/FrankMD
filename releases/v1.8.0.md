# v1.8.0

**Released:** 2026-10-10

Feature release: theme-aware fenced code highlighting (#227/#226), plus dependency maintenance.

## Features

- **Syntax highlighting in Markdown preview (#227, closes #226)**: fenced code blocks for JavaScript/TypeScript (incl. JSX/TSX), HTML/SVG, CSS, and JSON/JSONC are tokenized with the editor's bundled Lezer parsers and colored through the active theme's new `--theme-syntax-*` palette — all 18 built-in themes ship curated palettes, and Omarchy themes derive WCAG-contrast-adjusted syntax colors automatically. Unsupported languages render unchanged with no language label.
- Highlighting runs after sanitization using DOM APIs only (no HTML string concatenation); code content stays text by construction and an XSS-smuggling regression test pins that invariant. Source-line mapping, scroll-sync, and the live editor are unaffected (regression-tested).
