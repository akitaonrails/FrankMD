# v1.10.0

**Released:** 2026-10-20

Minor release: active media storage management, a redesigned minimal workspace, and dependency maintenance. Changes since v1.9.0 (`4937c92..HEAD`, 64 commits).

## Features

- **Active media storage (#234/#235)**: image imports and the picker work against the currently active storage — local or S3 — with automatic recovery for invalid S3 configuration/regions (falling back safely with a warning when S3 recovery selects Local), BMP MIME alias preservation on import, and browsing of both local image collections.
- **Reduced, cleaner writing workspace (#240/#241)**: one document header with inline title rename (reusing the file-operation validation, draft protection, and path remapping — one shared `renamePath` implementation behind both UIs); compact icon actions with tooltips, an overflow menu, and pinnable actions (session-scoped); Explorer file actions in its header with branding/Library/Settings in its footer; Explorer can close completely (mobile gets a dismissible overlay); a single shared header for editing and preview including zoom controls; About moved into Settings; Stats optional and off by default (`show_stats` config key); simplified editor borders, selection, and scrolling. 667 lines of new system-test coverage.
- CI actions bumped: ruby/setup-ruby (official master pin, adds Ruby 4.1-preview support), actions/setup-node v7.1.0 (SHA-verified).

## Test Coverage

- 1,123 Ruby tests (4,271 assertions), 2,156 JavaScript tests (90 files); full `bin/ci` green on the release tree; hosted CI green on every merge SHA in range.
