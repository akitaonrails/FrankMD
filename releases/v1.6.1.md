# v1.6.1

**Released:** 2026-10-03

Maintenance release: typewriter-mode layout fixes (#210/#209) and dependency updates.

## Fixed

- **Typewriter mode no longer changes Explorer visibility (#210, fixes #209)**: the typewriter toggle now manages editor presentation only; the sidebar stays as the user chose it.
- **Typewriter cursor centering after reveal (#210)**: enabling Typewriter mode while the editor workspace is hidden (e.g. from Settings) no longer leaves stale zero-height padding/cursor positioning — layout is recalculated when the editor becomes visible or resizes (ResizeObserver), with regression coverage for both behaviors.
- **Test-stability**: theme UI-selection tests no longer leak real debounce timers between tests (root cause of the intermittent `theme_controller` CI flake, tracked in #211).
