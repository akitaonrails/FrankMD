# v1.6.0

**Released:** 2026-10-01

Feature release: configurable view mode (#204) and interactive task completion (#203), plus dependency maintenance.

## Features

- **Configurable document view mode (#204)**: Settings > Editor gains Split View / Single View (persisted as `view_mode`, default split). Single mode shows exactly one full-width pane; the preview toggle switches panes, preserving autosave/undo/slash state (hidden-not-disconnected). Boot applies the configured mode; Settings applies live.
- **Interactive task completion (#203)**: clicking a preview task checkbox toggles the corresponding `[ ]`/`[x]` in the source — per-item line mapping in the preview, click replayed as a normal editor transaction (one undo step, autosave sees one edit). New **Ctrl+Enter** shortcut toggles the task state of the current line — or each selected line — and adds `- [ ]` to plain lines. Works in both view modes. The sanitizer keeps only the orphan checkbox shape (`type`/`checked`); every other form control remains forbidden.

## Dependency maintenance

- Vendored `dompurify` 3.4.13 → 3.4.16 (low-severity advisory for 3.4.13–3.4.15: IN_PLACE node-removing hook leaves detached-subtree handlers armed). New build fetched from jsDelivr+unpkg with identical SHA256; sanitizer suite green.
- `brakeman` 8.0.6 → 8.1.0 — 8.0.6 exits `Not_Latest_Version_Exit_Code` (5) whenever a newer release exists on rubygems, which broke the gate with zero code findings.

## Test Coverage

- 931 Ruby tests (3,286 assertions), 1,966 JavaScript tests; hosted CI green on the release tree (all five jobs including `test_ruby`).
